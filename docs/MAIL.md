# Отправка писем школам

Откройте страницу «Почта» (`/mail`) и отметьте школы с заполненной почтой. Можно также отметить школы в реестре и нажать «К письмам». Выберите до 20 школ за раз. В панели «Письма школам» выберите шаблон, отредактируйте текст, проверьте предпросмотр, введите код доступа и подтвердите отправку. На месте `{{школа}}` приложение подставляет название получателя. Каждой школе отправляется отдельное письмо. Когда SMTP-сервер принял письмо, статус «Письмо не отправлено» меняется на «Ожидается ответ».

## Настройка

Добавьте в локальный `.env.local` или в переменные окружения сервера:

```dotenv
SMTP_HOST=smtp.example.org
SMTP_PORT=587
SMTP_USER=school-office@example.org
SMTP_PASS=
MAIL_FROM=school-office@example.org
MAIL_ACCESS_CODE=
```

Укажите адрес отправителя, разрешённый вашим почтовым сервером. Для порта 587 используется STARTTLS, для 465 — TLS с начала соединения. Задайте случайный код доступа длиной от 16 символов и передайте его сотрудникам по внутреннему каналу. После изменения настроек перезапустите приложение. Для доступа сотрудников по сети разместите приложение во внутренней сети за HTTPS.

Во вкладке «Шаблоны» можно создать и отредактировать свои шаблоны. Они сохраняются в общей базе и доступны во вкладке «Отправка». Если браузер потерял ответ, кнопка «Повторить запрос отправки» проверяет ту же рассылку по её идентификатору. Если результат отмечен как неподтверждённый, сверьтесь с журналом почтового сервера перед новой отправкой.

Во вкладке «Отправленные» видны адрес получателя, тема, дата и результат отправки. В фильтре «Давно ждут ответа» можно выбрать срок от последнего принятого почтовым сервером письма — 7, 14 или 30 дней. Отметьте школы и нажмите «Подготовить напоминание». Отправка выполняется после предпросмотра и подтверждения кодом доступа.

## Входящие ответы

На странице «Почта» откройте «Ответы от школ». Ответы доступны всем, у кого есть доступ к приложению. Вкладка обновляется каждую минуту, пока открыта. Показываются до 50 последних найденных ответов на рассылки за 90 дней из папки «Входящие». Ответ связывается с отправленным письмом и адресом получателя. Для старых писем без сохранённого идентификатора приложение также сверяет тему ответа и показывает его, если школу можно определить однозначно. Статус такой школы меняется на «Ответ получен».

Для Mail.ru по умолчанию используется `imap.mail.ru:993` и пароль приложения из настроек отправки. Если пароль выдан только для SMTP, создайте пароль с доступом по IMAP и задайте `IMAP_PASS` в окружении сервера. Для другого почтового сервиса можно задать `IMAP_HOST`, `IMAP_PORT` и при необходимости `IMAP_USER`.
