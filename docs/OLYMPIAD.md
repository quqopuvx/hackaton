# Олимпиада «Точка старта»

Запустите `npm run dev` и откройте [раздел олимпиад и курсов](http://localhost:5173/olympiad/). После регистрации откроется каталог. В нём доступны пробная олимпиада «Точка старта» с тремя заданиями, мини-курс и памятка. Кабинет «МеркурИИй» доступен на главной странице приложения.

Олимпиада использует встроенный SQLite. Файл `.olympiad-data/registrations.sqlite` создаётся автоматически и исключён из Git. Для отдельной сборки можно использовать `npm run build` и `npm start`.

Используйте вымышленные имена и тестовые адреса. При регистрации нужно выбрать школу из реестра. Согласие `demo-v2` охватывает имя, почту и школу. Если у прежней регистрации школы ещё нет, её можно указать при повторной регистрации. Выбранная школа и первоначальный выбор о приглашениях сохраняются при следующих регистрациях с тем же адресом.

В кабинете «МеркурИИй» откройте «Реестр» и нажмите на название учреждения. В карточке школы появятся абитуриенты, выбравшие её при регистрации. Список доступен сотрудникам после входа в кабинет.

## Передача контактов агенту

1. Задайте случайный серверный секрет `OLYMPIAD_AGENT_TOKEN` длиной от 32 символов и передайте его агенту через хранилище секретов.
2. Агент запрашивает `GET /api/olympiad/invitation-contacts` с заголовком `Authorization: Bearer <токен>`.
3. Ответ содержит `contacts` с именами и адресами участников, выбравших приглашения, `nextCursor` и `hasMore`. Передавайте `nextCursor` в параметре `after` для следующей страницы. Новую выгрузку начинайте без курсора, сверяя адреса с уже обработанными. Версия согласия находится в `consentVersion`.

API выдаёт контакты с действующим согласием. Для отдельного агента подключение к API настраивается отдельно.

## Письма абитуриентам

В реестре откройте карточку школы и нажмите «Написать письмо» у абитуриента с действующим согласием на приглашения. Введите тему, текст и действующий код отправки. `{{имя}}` в тексте заменяется именем получателя. В письмо добавляется персональная кнопка «Отказаться от рассылки». После подтверждения отказа контакт исключается из ручной и автоматической рассылок и выдачи контактов для агента.

Для отправки используйте настройки SMTP из `MAIL.md` и задайте `APPLICANT_MAIL_ORIGIN` с доступным получателям HTTPS-адресом. Этот адрес должен вести к тому же серверу по маршруту `/api/olympiad/unsubscribe/`. Если отдельная переменная отсутствует, используется HTTPS-адрес из `APP_ORIGIN`. На localhost можно составить письмо. Реальная отправка доступна после настройки HTTPS-ссылки отписки.

В «Настройки → Автоматические рассылки» администратор может выбрать задержку 7, 14 или 30 дней после регистрации и задать тему и текст. По умолчанию рассылка отключена. При работающем сервере подписавшиеся школьники получают по одному автоматическому письму, включая ранее зарегистрированных, если их срок уже пришёл. При неизвестном результате SMTP автоматическая повторная отправка не выполняется.
